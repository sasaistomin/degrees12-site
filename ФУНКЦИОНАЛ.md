# DEGREES° 12 — как работает сайт

## Файлы
| Файл | Для чего |
|---|---|
| `index.html` | Страницы сайта: Главная, Каталог, Категории, О нас |
| `style.css` | Внешний вид (цвета в блоке `:root`) |
| `script.js` | Логика сайта: карточки, фильтр, сортировка, загрузка из базы |
| `products.js` | Запасные товары. Показываются, пока `config.js` пустой или база недоступна |
| `config.js` | Адрес и публичный ключ Supabase |
| `admin.html` | Админ-панель (адрес `ваш-сайт/admin`) |
| `supabase.sql` | Создаёт таблицы, права доступа, хранилище фото и переносит ваши товары |
| `vercel.json` | Включает короткий адрес `/admin` |
| `photos/`, `logo.jpg` | Старые фото и логотип (остаются как были) |

## Сайт для покупателей
- **Главная:** большой заголовок, плитки категорий, «Новые поступления» (4 последних добавленных товара).
- **Каталог:** все товары, фильтр по категории, сортировка по цене (дорогие/дешёвые).
- **Категории:** плитки с количеством вещей в наличии; клик открывает каталог с фильтром.
- **О нас:** текст и контакт. Меняется вручную в `index.html` (поменяйте `@degrees12` на свой контакт).
- **Карточка товара:** фото (или цветная плитка без фото), название, категория, размеры, цена. Проданные товары серые с пометкой «Продано». Скрытые товары не показываются.
- Товары и категории подтягиваются из базы при каждом открытии сайта: изменения из админки видны сразу.

## Админка

- **Сводка:** всего товаров, в наличии, продано, скрыто, категорий.
- **Добавить / изменить товар:** название, категория, цена, размеры галочками (XS–XXL, 38–46) и поле для своих размеров (например `One size`), фото.
- **Фото:** загрузка с телефона или компьютера. Фото уменьшается до 1200 px и хранится в Supabase. PNG остаётся PNG (прозрачный фон сохраняется).
- **Кнопки у товара:** «Продано / Вернуть», «Скрыть / Показать», «Изменить», «Удалить».
- **Категории:** добавить (название + цвет плитки + цвет текста) или удалить.
- Новый товар сразу попадает в начало списка и в «Новые поступления».

## Как это устроено
Покупатель открывает сайт → `script.js` запрашивает у Supabase категории и нетскрытые товары → рисует страницы. Админ входит в `admin.html` → Supabase проверяет логин и пароль → разрешает менять данные. Никакого своего сервера нет: сайт на Vercel, данные и фото в Supabase.

## Безопасность
- Читать товары может любой, а менять данные и загружать фото — только вошедший админ (правила `is_admin()` в `supabase.sql`).
- Ключ в `config.js` публичный, это нормально: защищают правила базы, а не ключ.
- Обязательно выключите регистрацию новых пользователей (шаг 4), иначе кто угодно сможет создать аккаунт.
- Пароль можно сменить в Supabase → Authentication → Users.

## Настройка (один раз)

2. SQL Editor → вставьте весь `supabase.sql` → Run.
3. Authentication → Users → Add user → Create new user: **Email** `istomin.sasha.m@degrees12.shop`, **Password** `sasha1223m+`, отметьте Auto Confirm.
4. Authentication → Sign In / Providers → Email → выключите «Allow new users to sign up».
5. Project Settings → API: скопируйте Project URL и anon/publishable key в `config.js`.
6. GitHub: commit + push, Vercel обновит сайт сам.
7. Откройте `ваш-сайт/admin` и войдите.

## Ограничения
- При удалении товара его фото остаётся в хранилище Supabase (можно удалить вручную).
- Заказов и корзины нет: покупатель связывается с вами по контакту из «О нас».
- Текст «О нас» меняется только в `index.html`.
